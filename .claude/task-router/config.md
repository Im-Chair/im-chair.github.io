# Task Router 專案設定

> 由 `/task-router:router-setup` 產生，可直接手動編輯。

## 基本偏好

- 輸出語言：繁體中文（臺灣用語）
- 子代理權限：可直接修改 brief 指定的檔案；不可 commit、push。稽核與審查類任務一律唯讀，由主模型核對後套用
- 預設規則包：development

## 模型對應

| 難度 | 模型 |
|---|---|
| L | haiku |
| M | sonnet |
| H | opus |

- 分派時一律指定 task-router 的執行者，不用一般用途 agent（它會沿用主模型 Opus，無法依難度省額度）。
- 設定決策、數值取捨、驗收由主模型做；決策確定後的改寫、批次產出交給 sonnet；大檔案偵察、機械式替換交給 haiku。
- 要判斷劇情或設計的審查先派 sonnet，不夠再升級 opus。

## 外部 AI

| provider | 狀態 | 允許寫入檔案 | 適合的工作 |
|---|---|---|---|
| codex（ChatGPT） | 停用（本機未安裝，2026-11-05 偵測） | 否 | 程式 L／M、第二意見審查 |
| gemini（Google） | 停用（本機未安裝，2026-11-05 偵測） | 否 | 大量讀取偵察、翻譯初稿、第二意見 |

安裝 CLI 並登入後，把「狀態」改成「啟用」。

## 專案資訊

- 主要語言／框架：原生 HTML / CSS / JS，無框架（GitHub Pages 靜態 PWA）
- 建置指令：無（零 build）
- 測試指令：無測試框架。本機預覽 `python -m http.server 8000`；單檔遊戲用 `node` 的 `vm.Script` 檢查內嵌 script 語法，再到瀏覽器實測
- 風格範例檔：`sky-frontier/index.html`
- Node 路徑：`C:\Program Files\nodejs\node.exe`（可能不在 PATH）

## 不可修改

- 既有的 game-icons.net 授權標註（CC BY 3.0）不可移除
- `.gitignore` 列為本機專用的開發文件與素材：除非 brief 明確指定，否則不要改

## 專案規則

1. 遵守 `CLAUDE.md`：繁體中文介面與註解、零依賴、沿用暗色美術系統，不引入框架、build 工具或 npm 依賴。
2. commit、push 只由主模型在使用者同意後執行；推送到 main 就會上線。
3. 改到需要立即生效的資源，要升對應 `sw.js` 的 `CACHE`；改 rpg 的 js／css，要升 `rpg/index.html` 的 `RPG_VER`。
4. 改寫含 base64 的大型單檔（`pokemo/`、`drift-ark/`）時，用腳本做字串替換，並斷言每個目標只出現一次；不要把整個檔案讀進對話。
5. 暫存與測試輸出放 `output/`，完成後清掉。
6. 不改每日挑戰（數獨、掃雷、幾A幾B）的產生器或亂數消耗順序，除非使用者同意；上線當天更不能改。
7. 遊戲文字：不寫冗長過場、自言自語，也不要把玩家當傻子。操作失敗要有簡短、實用的提示。
8. 改劇情或台詞前，先確認角色當下知道什麼、已發生什麼，以及不同觸發順序下是否仍成立。
9. 巡檢類工作超過 5 個獨立對象時一定要拆：先派 sonnet 寫各對象的測試流程，主模型只核對疑點與判斷結果。
10. 派工前先實測執行者能不能用瀏覽器分頁（各自開分頁、帶 tabId），不要直接假設只能由主模型操作。實測結果記到 `learned.md`。
11. 單次瀏覽器腳本控制在 30 秒內（工具上限 45 秒），回傳內容要精簡，只回判斷需要的欄位。
