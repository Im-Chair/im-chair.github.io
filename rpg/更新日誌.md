## 使用說明

### 兩個版號,用途不同,不要合併

兩者都在 `rpg/index.html` 的 `<head>`:

| 常數 | 什麼時候 +1 | 影響 |
|---|---|---|
| `RPG_VER` | 改任何 `.js` / `.css` | 自動套到 CSS 連結、所有 `<script src>` 的 `?v=`、標題畫面顯示的 `V4.NN` |
| `IMG_VER` | **只有真的換圖時** | 所有 `mon/` `ui/` `eq/` 圖片與 `camp3.webp`、`title_bg.webp` 的 `?v=` |

**為什麼拆開**:圖片有 121 張、共 3.0 MB。v393 到 v420 這 27 次進版,圖片一直跟著 `RPG_VER` 變 URL——瀏覽器整批重抓、Service Worker 快取每版累積一整套重複 entry,而圖根本沒動。v421 拆開之後這個浪費停止。

### 站台層級的快取

根目錄 `sw.js` 的 `CACHE`(`arcade-vNN`)是**獨立的第三個版號**,跟上面兩個無關。需要讓「已安裝 App 的舊使用者」立刻拿到資源時 +1,舊快取會在 activate 時清除。

策略是 **network-first**(先打網路、失敗才回快取)。**不要改成 cache-first**——`/rpg/index.html` 沒有版號,cache-first 會永遠餵舊的 index.html → 舊的 `RPG_VER` → 整個版本機制失效。

### 新增圖片是三件事,缺一不可

1. **放檔** — `mon/<key>.webp` / `ui/<slug>.webp` / `eq/<slug>.webp`,**檔名就是資料表的 key/slug**
2. **資料掛勾** — 怪物在 `data.js` 該筆加 `img:1`;裝備加進 `ITEM_ICON`;事件加進 `EV_IMG`
3. **快取進版** — 根目錄 `sw.js` 的 `RPG_MON`/`RPG_UI`/`RPG_EQ` 補一筆 + `CACHE` +1,並把 `IMG_VER` +1

> 只換內容、檔名不變時,第 1、2 項看起來免做——**第 3 項還是要做**,否則破不了快取。

### 部署

桌面資料夾**不是 git repo**,手動上傳到 `im-chair/im-chair.github.io`。上傳範圍是 **`rpg/` 整包 + 根目錄 `sw.js`**。曾經漏傳根目錄的 `sw.js`,結果線上 `rpg/` 是新的、`sw.js` 停在兩週前——有網路時看不出來,離線就缺圖。

## v430 — 懸賞板紙條改 transform：修橫向捲軸、疊放、選中浮起
`CACHE=arcade-v41`(未變動)

回報「三張卡片＋間距比底色塊還寬,可以左右滑」。

**根因**:v429 的錯落是 `margin-top` ＋ `rotate()`。`rotate()` 之後元素的**外框**比原本寬——
88×110 的紙條轉 4° 大約多出 8px——三欄一加就撐破 `.bn-grid`,於是出現橫向捲軸。

**修法:錯落與疊放全部改走 `transform`。** `transform` 不影響 layout,容器寬高固定,
捲軸的來源直接消失。`BN_ROT` ＋ `BN_OFF` 兩個常數合併成一個 `BN_TF`
(`translate() rotate()` 字串),另加 `BN_Z` 控制疊放順序。

順帶把錯落做成**真的微堆疊**:欄距 `gap` 7px→2px、`translateX` 給到 ±7px,紙條會互相疊到約 6px。
`BN_Z = [3,1,4,2,5,1]` 刻意亂序——照 DOM 順序疊會像整齊的魚鱗。

**選中改成「拿起來」**:`transform:none` → `scale(1.05)`、`z-index:9`、陰影加深到
`0 8px 18px`。`z-index` 是關鍵,紙條彼此重疊,沒有它金框會被鄰居蓋住。

**踩到的坑:`overflow-x:hidden` 把金框裁掉。**

加了 `overflow-x:hidden` 殺捲軸之後,選左右兩欄的紙條時最外側那道金框不見了。
不是被鄰居壓住,是被容器裁掉——左右兩欄本來就 `translateX` 往外偏 7px,
被選中再 `scale(1.05)` 又往外長約 3px,合計超出內容框 11px,正好落在裁切線外。
中間欄不會,因為它沒貼邊。

修法是 `.bn-grid{padding:10px 14px 30px}` ——**這個 padding 不是留白,是縮放的預留空間**,
註解已寫在 CSS 裡。左右 14px 覆蓋 7+3 的外擴,下方 30px 是因為 `transform` 的位移不撐開容器,
往下偏的那排不留白會被切。`.bn-board` 的左右 padding 相應從 9px 收到 5px,紙條實際大小不變。

`.bn-note` 寬度 `calc(33.333% - 5px)` → `- 2px`(gap 縮小),`.bn-key` 的 `margin-top`
12px→2px(下留白已由 grid 的 padding 提供)。

`_smoke.js` 與 18 項懸賞板測試全過。

## v426 — 懸賞板撐滿畫面
`CACHE=arcade-v41`(未變動)

實機看到懸賞板只佔畫面上半,下方一大片黑。`.screen` 本身是 flex column,
